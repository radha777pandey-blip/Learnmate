🎯 What is LearnMate?

LearnMate is an AI-powered recommendation platform designed to help students discover the best books, online courses, coding platforms, and skill roadmaps — fully personalized.

✨ Features

  • 📚 Personalized Book Suggestions
  • 🎓 MOOC & Certification Course Recommendations
  • 💻 Coding Practice Platforms and Challenges
  • 🚀 Skill Roadmaps for Career Growth

🧠 How the AI Works?

LearnMate uses TensorFlow-based NLP models to understand user interests and course/book descriptions. It then generates personalized recommendations using:

  • ✔ Semantic vector embeddings
  • ✔ Similarity matching
  • ✔ User learning history
  • ✔ Content relevancy score

🛠️ Technologies Used

  • 🎨 HTML, CSS, JavaScript (3D UI)
  • ⚙️ Spring Boot + MySQL (Backend)
  • 🤖 TensorFlow (Recommender AI)
  • 🌐 Coursera API + LeetCode Data
