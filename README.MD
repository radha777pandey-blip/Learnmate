# 📘 Learn Mate: AI-Powered Learning & Skill Recommender

> **Tagline:** Helping students discover the right books, courses, and coding opportunities.

---

## 🎯 Project Objectives
- Provide personalized book recommendations for different subjects  
- Suggest relevant online courses (MOOCs, tutorials, certifications)  
- Recommend coding practice platforms and challenges  
- Promote structured skill development for students  

---

## 🛠️ Tech Stack
**Frontend:** HTML, CSS, JavaScript  
**Backend:** Django (Python)  
**AI/ML:** TensorFlow  
**Database:** MySQL  
**Tools:** Git, GitHub  

---

## 🧰 Facilities Required
- **Software:** Python, Django, TensorFlow, MySQL, HTML, CSS, JavaScript  
- **Hardware:** Laptop (≥8GB RAM) + Internet  

These are sufficient for development and deployment.

---

## 🚀 Expected Outcomes
An AI-powered system that:
- Helps students find learning materials faster  
- Improves study efficiency  
- Guides students toward academic and career goals  

---

## 💡 Feasibility Study
| Aspect | Description |
|--------|--------------|
| **Technical** | Achievable using Django, TensorFlow, and MySQL |
| **Operational** | Simple and accessible web interface for students |
| **Economic** | Uses open-source tools, low-cost, feasible for students |
